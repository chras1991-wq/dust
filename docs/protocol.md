# SATDUST Protocol Notes

- DUST-20 v1.1.0 (2026-09-01), Bitcoin mainnet, Experimental
- Meta-protocol: inscription + UTXO/satoshi flow (not Bitcoin consensus)
- Ticker case-fold; first valid deploy wins
- Mint carrier output sats must equal declared `sats`; inscription offset must be 0
- No separate transfer op — spends derive allocation

See `/docs` on the site for operator-facing pages.
